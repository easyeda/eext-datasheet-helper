# データシートAIアシスタント

嘉立創EDA Pro Edition 拡張機能 — 回路図のコンポーネントを選択し、データシートを自動取得して、AI対話で技術的な質問に答えます。


## デモ

**コンポーネントを選択し、メニューからAIチャットを開く**

![コンポーネント選択メニュー](./images/image.png)

**AIチャットウィンドウ — データシートを自動読み込み、ストリーミングQ&A**

![AIチャットウィンドウ](./images/image1.png)

## 機能

- **ワンクリック起動**：回路図でコンポーネントを選択し、メニューからAIチャットウィンドウを素早く開きます
- **データシート自動取得**：コンポーネントに関連付けられた Datasheet URL を自動的に読み込み、PDF をダウンロードします
- **スマートPDF解析**：
  - テキスト型 PDF：テキストを直接抽出（pdf.js）
  - スキャン型 PDF：OCRに自動的に切り替え（Tesseract.js）
- **オンデマンド検索**：ユーザーの質問キーワードに基づいてデータシート内の関連段落をインテリジェントにマッチングし、一致しない場合は自動的にページを拡張して解析します
- **AIストリーミングチャット**：OpenAI 互換 API に基づき、SSE ストリーミングでリアルタイム出力します
- **コンテキスト管理**：対話履歴を自動的に保持し、最新6件まで維持します
- **Markdownレンダリング**：コードブロック、テーブル、リストなどのリッチテキスト表示をサポートします
- **ライト/ダークテーマ対応**：システムの配色に自動的に追従します
- **カスタムAPI設定**：APIエンドポイント、キー、モデル名を設定可能です

## クイックスタート

### インストール

1. 拡張パッケージ（`.eext` ファイル）をダウンロードします
2. 嘉立創EDA Pro Edition を開きます
3. **詳細設定 → 拡張機能マネージャー → アップロード/インストール** に移動します
4. ダウンロードした `.eext` ファイルを選択してインストールします

### 使用手順

1. 回路図でコンポーネントを1つ選択します
2. トップメニュー **データシートAIアシスタント → AIチャットを開く** をクリックします
3. 初回使用時、ウィンドウ右上の ⚙ アイコンをクリックしてAI API設定を行います：
   - **APIエンドポイント**：例 `https://api.openai.com/v1`
   - **APIキー**：AIサービスのキー
   - **モデル名**：例 `gpt-4o-mini`
4. データシートの読み込みが完了したら、入力ボックスに質問を入力します

> [!TIP]
> 質問例：主要な電気的特性を列出して、ピン配置を教えて、パッケージ情報、動作電圧範囲 など

## 権限要件

| 権限 | 用途 |
|------|------|
| 外部通信権限 | PDFデータシートのダウンロード、AI APIの呼び出し |

PDFダウンロードに失敗した場合は、拡張機能マネージャーで本拡張機能の**外部通信権限**が有効になっていることを確認してください。

## 技術スタック

- [pdf.js](https://github.com/mozilla/pdf.js) — PDFドキュメント解析
- [Tesseract.js](https://github.com/naptha/tesseract.js) — OCRテキスト認識
- OpenAI互換 API — AIチャット（SSEストリーミング）

## プロジェクト構成

```
datasheet-ai-assistant/
├── src/
│   └── index.ts            # 拡張機能メインエントリ
├── iframe/
│   ├── chat.html           # AIチャットウィンドウ（HTML + インラインCSS/JS）
│   ├── chat.js             # チャットウィンドウJSロジック（ソース）
│   └── chat.css            # チャットウィンドウスタイル（ソース）
├── images/
│   └── logo.png            # 拡張機能アイコン
├── extension.json          # 拡張機能設定ファイル
├── package.json            # プロジェクト依存関係とビルドスクリプト
└── build/
    └── dist/               # コンパイル済み .eext 出力
```

## ソースからビルド

```shell
# 依存関係のインストール
npm install

# コンパイルとパッケージ化
npm run build
```

生成された拡張パッケージは `./build/dist/` に配置されます。
